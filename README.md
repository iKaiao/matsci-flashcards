## 上传到 GitHub Pages

1. 克隆现有 `iKaiao/matsci-flashcards` 仓库（GitHub Desktop）。
2. 解压本包，把包内的所有文件与文件夹拷到克隆的仓库根目录，覆盖同名文件。
3. **保留仓库已有的 `.git` 和 `CNAME`**；此包不包含它们。
4. 在 GitHub Desktop `Commit to main` 然后 `Push origin`。
5. 打开 Pages 网站，必要时无痕访问或强制刷新。
