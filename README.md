# 材料科学基础 · 网页记忆卡片

依据用户提供的《材料科学基础学习指导》PDF 制作，适合手机、平板和电脑浏览器，支持离线打开。

## 快速使用

1. 解压完整 ZIP 压缩包，保持 `index.html` 和 `book.pdf` 在同一文件夹。
2. 双击 `index.html`，使用 Chrome、Edge、Safari 等现代浏览器打开；如遇手机文件管理器不支持直接打开 HTML，可将整个文件夹部署为静态网站（下文说明）。
3. 在左侧/手机菜单选择章节与题型。读题后回忆，点击卡片“翻面”，再按“不会 / 模糊 / 会了”。
4. 电脑端右侧常驻「随卡笔记」；手机端可用悬浮「写笔记」按钮呼出记录面板。每张卡片的笔记分别保存。
5. 每张卡片都可点击「题目原页」或「答案原页」查看随包附带的原书 PDF 页。

## 包含哪些内容

- 11 章共 **303 张卡片**，其中：疑难解析 49、例题 58、习题 177、综合思考题 19。
- 支持按章节、类型、关键词和学习状态筛选；浏览全文卡片库、收藏、记录掌握情况、查看学习概览。
- 记忆卡片背面提供提取自原书的参考解析；第 11 章综合思考题在原书中没有给出答案，因此标注需自行归纳。
- 部分数学公式、图示、上下标和个别汉字可能因扫描文本识别而失真；**请以随包 PDF 的原书页面为准**。卡片右上角「✎」允许更正本机内容，更正也包含在备份文件里。

## 笔记与进度保存

- **默认仅保存在本机浏览器的 localStorage 中，不会自动跨设备同步。**
- 电脑、手机、平板切换学习时，请点击「备份」导出 `.json`，在另一设备点击「导入」合并笔记、收藏与复习记录。
- 「我的笔记」还可导出 Markdown（`.md`）方便在笔记软件中继续整理。
- 切勿使用浏览器无痕模式长时间学习；浏览器清除网站数据、更换网址或本地文件路径，可能导致当前设备保存的记录不可用。建议定期导出 JSON 备份。
- 某些手机浏览器对从文件管理器打开的 HTML 保存数据有限制，建议把该网站部署到 HTTPS 地址使用；HTTPS 托管后支持缓存离线访问及添加到主屏幕。

## 如何部署成真正的网页

这套站点是纯静态文件，不需要数据库和服务器程序。

1. 在 Cloudflare Pages、GitHub Pages、Netlify 或任何静态网站托管服务新建站点。
2. 上传/部署 `index.html`、`book.pdf`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`、`apple-touch-icon.png`，放在网站根目录。
3. 通过 HTTPS 网址在手机、平板和电脑中打开。

**注意：部署同一个网址并不意味着笔记会自动同步。** 这是刻意采用的离线、本地优先设计。需要跨设备同步时用 JSON 导出/导入。

## 键盘快捷键

空格：翻面；← / →：上一张 / 下一张；1 / 2 / 3：不会 / 模糊 / 会了；N：跳到笔记；/：搜索；Esc：关闭面板。

## 文件结构

- `index.html`：**全部卡片数据和界面代码已经打包其中**，可直接打开。
- `book.pdf`：原书扫描件，用来核对题目、公式、图表与解析。
- `manifest.webmanifest`、图标及 `sw.js`：用于 HTTPS 环境下的离线缓存和安装到主屏幕。
- `source/`：可选源文件，供以后修改卡片内容或界面并重新生成 `index.html`。
