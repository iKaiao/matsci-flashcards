# 材料科学基础 · 图文答案纠错版（v5）

包含全部 303 张卡片、两份参考 PDF、两种 PDF 的**完整页面图片**（原书 150 页，纠错资料 120 页）、笔记、离线访问和学习进度。

## 图片答案纠错

1. 打开一张卡片，翻到答案，点 **✎ 直接纠错答案**。
2. 选择 **文字答案 / 图片答案 / 图文结合**。
3. 使用“本题关联页”快捷添加，或在下拉框中选择**任意原书 / 纠错 PDF 页码**。
4. 点击“框选答案”，用鼠标或手指拖动选择答案所在矩形，保存选区；可以添加多张并调整顺序。
5. 也可以点击“从相册 / 电脑选择图片”上传 PNG/JPEG/WebP；上传后同样可以框选。
6. 保存后立即将图文答案应用到当前卡片，**原书扫描图片保留在折叠区**。

- 文字纠错和选择的原书页面保存在本机浏览器的旧版学习记录中；上传图片存放在浏览器 IndexedDB，不易触及普通 localStorage 大小限制。
- **先备份再清理浏览器**：导出的 `材料科学基础_笔记进度与图片答案备份.json` 会将上传图片与笔记、进度一起备份。跨设备请导入备份。
- 个人纠错仅在当前浏览器生效。要让 GitHub Pages 所有访客看到修订，在“我的答案纠错”导出 `site-corrections.json`（会包含公开发布的图片，不含私人笔记），将其覆盖仓库根目录中的同名文件，然后在 GitHub Desktop **Commit to main → Push origin**。
- 不要删除仓库的 `.git` 与 `CNAME`，自定义域名 `card.mikus.cc` 无须重新配置。
- 框选 PDF 页是基于站点自带图片进行的，无须额外上传 PDF。站点包含两份 PDF 和完整页面扫描图，请确认有公开发布和使用这些资料的权限。
